# Move quality markers (PNG)

Replace any file in this folder — the board loads them by name:

| File | Meaning |
|------|---------|
| `brilliant.png` | !! Brilliant |
| `great.png` | ! Great (avant Brilliant) |
| `best.png` | ! Best |
| `excellent.png` | ! |
| `good.png` | good / check |
| `inaccuracy.png` | ?! |
| `mistake.png` | ? |
| `miss.png` | X Miss / occasion manquée |
| `blunder.png` | ?? |
| `book.png` | opening theory |

Tips: square PNG, transparent background, ~128–256px, circular badge works best.
